## 💡 O que é Node.js?

**Node.js** é um ambiente de execução que permite executar JavaScript fora do navegador.

Ele possibilita utilizar JavaScript para desenvolver aplicações no lado do servidor, ferramentas de linha de comando, APIs, aplicações em tempo real, microsserviços e outras soluções.

## 🆚 JavaScript x Node.js

É importante entender que **JavaScript é uma linguagem de programação**, enquanto **Node.js é um ambiente de execução para JavaScript**.

### JavaScript no navegador

Normalmente é utilizado para:

* Manipular o DOM;
* Interagir com páginas Web;
* Responder a eventos;
* Alterar interfaces;
* Trabalhar com APIs do navegador.

### Node.js

Permite executar JavaScript fora do navegador e fornece recursos para:

* Criar servidores;
* Trabalhar com arquivos;
* Acessar o sistema de arquivos;
* Trabalhar com redes;
* Manipular streams;
* Criar APIs;
* Desenvolver ferramentas de linha de comando;
* Conectar aplicações a bancos de dados.
